# Преимущества:
- Дается много кредитов для генерации
- Есть настройки для 3д печати
- Есть возможность генирации модели с добавлением фотографий со всех сторон, но она так же платная


# Недостатки:
- Из бесплатного только есть возможность сделать обычное изображение в 3д
- Качество модели плохое, разрешение маленькое
- Без подписки ничего нельзя, почти все функции урезанные
